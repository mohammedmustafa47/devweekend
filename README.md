## How to Run Locally

Follow these steps to run the application on a fresh machine:

1. **Navigate to the Project Directory:**
   ```bash
   cd devweek
   ```

2. **Install Ionic CLI & Dependencies:** 
   This ensures the `ionic` command is recognized by your machine and downloads all project requirements:
   ```bash
   npm install -g @ionic/cli
   npm install
   ```
   

3. **Start the Application:** Run the local development server.
   ```bash
   ionic serve
 ```
